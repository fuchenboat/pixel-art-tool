# 像素画转换器 (Pixel Art Converter)

一款纯前端的在线图片转像素画工具。上传任意照片，拖动滑块实时调节像素块大小与颜色数量，一键导出 PNG / SVG 像素画。所有处理都在浏览器本地完成，图片不会被上传到任何服务器。

## 功能特性

- **图片转像素画**：Canvas 降采样将普通照片转换为方块像素风格
- **实时预览**：拖动滑块即时刷新效果，无需等待服务器渲染
- **像素大小调节**：1–64 级可调，数值越小细节越清晰，越大越复古
- **颜色数量调节**：2–256 色，采用中位切分（Median Cut）算法量化配色
- **多格式导出**：支持 PNG（1× / 4× / 8× / 16× 最近邻放大）与 SVG（矢量色块，可无限放大不失真）
- **多种上传方式**：点击选择、拖拽到页面、`Ctrl + V` 粘贴，支持 JPG / PNG / GIF / WebP / BMP，单文件最大 30MB
- **原图对比**：左栏原图、右栏像素画结果，同步预览
- **深浅主题**：右上角一键切换白色 / 深色主题，选择会被本地记忆
- **隐私安全**：图片仅在本机浏览器内处理，全程不上传
- **响应式布局**：桌面端双栏、移动端自动单栏

## 技术栈

| 类别 | 说明 |
| --- | --- |
| 结构 | HTML5 语义化标签，首页 / 关于双视图单页切换 |
| 样式 | CSS3：CSS 自定义属性（主题变量）、Grid、Flexbox、媒体查询 |
| 脚本 | 原生 JavaScript（ES5 风格 IIFE），无框架、无第三方依赖、无构建步骤 |
| 图形 | Canvas 2D API：`drawImage` 降采样、`getImageData` / `putImageData` 像素读写 |
| 算法 | 中位切分（Median Cut）颜色量化 + 5 位色彩查找表（LUT）最近色匹配 |
| 存储 | `localStorage` 记录主题偏好 |
| 导出 | `canvas.toBlob()` 生成 PNG；字符串拼接生成 SVG 的 `<rect>` 色块 |

## 安装步骤

项目为纯静态页面，无需安装依赖或构建。

1. 克隆仓库

   ```bash
   git clone https://github.com/<your-name>/<repo-name>.git
   cd <repo-name>
   ```

2. 直接打开 `index.html` 即可运行；若希望以 http 方式访问，可在项目根目录启动任意静态服务器：

   ```bash
   # 方式一：Python
   python -m http.server 8123

   # 方式二：Node.js
   npx serve .
   ```

   然后访问 `http://localhost:8123`。

## 使用方法

1. 进入「首页」，点击上传区选择图片，或把图片拖拽到页面，也可直接 `Ctrl + V` 粘贴剪贴板中的图片。
2. 左侧显示原图，右侧实时显示像素画效果。
3. 拖动「像素大小」滑块调整方块粗细（1–64）：数值越小越接近原图，越大越复古。
4. 拖动「颜色数量」滑块调整配色数量（2–256）：数值越小越有复古游戏感。
5. 在「导出放大倍数」中选择 1× / 4× / 8× / 16×，再点击「导出 PNG」或「导出 SVG」保存文件。
6. 点击「换一张图」可重新选择图片。
7. 点击右上角图标可在浅色 / 深色主题之间切换；点击导航「关于」可查看项目功能说明。

### 导出说明

| 放大倍数 | 133 × 100 网格导出的 PNG 尺寸 |
| --- | --- |
| 1× | 133 × 100 px |
| 4× | 532 × 400 px |
| 8× | 1064 × 800 px |
| 16× | 2128 × 1600 px |

放大采用最近邻插值，只复制像素、不做模糊，方块边缘保持锐利。SVG 为矢量格式，放大倍数只决定文件的默认显示尺寸，不影响清晰度。

## 性能说明

为保证大图下依然流畅，处理管线内置了以下保护：

- 原图先归一化到最长边 1600px 再参与像素化
- 像素网格最长边限制 1200px、总像素上限 64 万
- 调色板构建时最多采样 2 万个像素
- 滑块事件使用 `requestAnimationFrame` 节流，并对过期渲染结果做丢弃处理

## 浏览器兼容

推荐使用 Chrome、Edge、Firefox、Safari 的最新版本（依赖 Canvas 2D、CSS 自定义属性、`object-fit` 与 `localStorage`）。
